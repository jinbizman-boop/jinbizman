# JINBIZ 공식 홈페이지 콘텐츠 고도화 적용 보고서

## 적용 목표

기존의 디자인·레이아웃·다국어 구조를 유지하면서, 공식 홈페이지가 `회사 정의 → 해결 문제 → 제공 가치 → 실제 근거 → 현재 상태 → 다음 행동`의 흐름을 갖도록 콘텐츠를 재구성했다. 회사·서비스에 관한 검증되지 않은 수치, 출시, 운영, 투자, 파트너십과 실적을 생성하지 않았으며, 개발 프로젝트는 현재 단계와 다음 검증 항목을 분리했다.

## 공개 페이지 변경

### 메인 홈

- 아이디어·AI 도구·운영의 세 가지 단절을 설명하는 문제 카드 추가
- 네 개 개발 프로젝트 포트폴리오 추가
- 기획에서 운영까지 연결, B2B·공공·플랫폼 경험, 문서·시각 결과 통합, 5개 언어 운영 구조를 신뢰 근거로 표시
- 초기 공식 공지 3건을 최신 소식으로 노출
- Eureka World CTA를 실제 상세 페이지로 연결

### 회사소개

- 회사 한 문장 정의
- `우리가 존재하는 이유`
- `회사의 변화`: 축적·전환·확장
- `핵심 역량`: 문제 구조화, 서비스 설계, AI 적용, 시각화, 운영 체계
- 핵심 가치와 행동 기준
- 2020년 대외 활동 기록과 2026년 통합 사업 구조 정비
- `Company Facts`와 공식 확인이 필요한 법적 정보의 분리

설립 연도는 내부 문서 간 2018년·2020년 표현이 충돌하므로 확정하지 않았다. 2020년 외부 기사에 확인되는 활동만 대외 기록으로 표시했다.

### 사업소개

- 기존 3개 실행축 유지: AI 서비스 / 플랫폼 사업 / 기획 기반 역량
- 개발 프로젝트 4종을 상태와 함께 추가
- 5대 사업군과 사이버트론 프로젝트를 중장기 비전으로 유지
- 현재 제공 사업, 개발·검증 프로젝트, 중장기 포트폴리오를 구분

### 뉴스레터

초기 공개 검수용 원고 5건을 5개 언어로 생성했다.

1. 공식 홈페이지 개편 안내
2. 사업 방향 안내
3. 개발 프로젝트 포트폴리오 안내
4. 공식 도메인 및 다국어 운영 정책
5. 공식 문의 채널 운영 안내

발행일은 임의로 만들지 않고 ERP 관리자 승인 시 확정하도록 표시했다. 보도자료는 검증된 대외 발표가 없으므로 빈 상태를 유지한다.

### 문의하기

- AI 서비스, 플랫폼 기획·개발, 사업·서비스 기획, 제안서·소개서, 협업, 투자·파트너십, 미디어, 기타 문의 유형
- 프로젝트 단계, 희망 일정, 필요한 결과물, 참고 URL 선택 필드
- 문의 접수부터 프로젝트·WBS 전환까지 5단계
- 민감정보 입력 금지 안내
- FAQ 4개
- 정적 시연본의 브라우저 Mock 저장 한계 고지

## 프로젝트 상세 페이지

각 프로젝트를 5개 언어로 생성했다.

| 프로젝트 | 공개 상태 | 주요 공개 범위 |
|---|---|---|
| Eureka World | 개발 중 | 작업 지시, 결과물 생성, 프로젝트 연결 |
| New Retro Games | 개발 중 | 통합 게임 허브, 진행·보상·랭킹 |
| 급여납치 | 기획 중 | 급여·소비·생활 습관·자기계발 연결 |
| 모든평가 | 프로토타입 검증 중 | 평가 기준, 리뷰, 반응, 랭킹, 신고 확장 |

상세 페이지에는 대상, 확인된 핵심 범위, 현재까지의 작업, 상태 투명성, 다음 검증 단계를 포함한다. `운영 중`, `공식 출시`, `상용화 완료`, `100% 완성`을 사용하지 않는다.

## 다국어 및 SEO

- 한국어, 영어, 일본어, 프랑스어, 스페인어 상세 페이지 생성
- 동일 콘텐츠의 언어 전환 링크 유지
- canonical과 5개 hreflang 연결
- 언어별 미발행 fallback 금지 원칙 유지
- 검색 인덱스와 sitemap에 프로젝트·뉴스 상세 추가

## 정적 구현의 한계

이번 ZIP은 디자인·콘텐츠·화면 흐름·브라우저 인터랙션을 검증하기 위한 정적 HTML 통합본이다. 실제 Neon DB 저장, 이메일 발송, 인증, 서버 권한 검증, Queue, 파일 스토리지와 운영 배포는 포함하지 않는다. API·DB 기준 문서와 참고 SQL은 다음 개발 단계의 근거이며 실제 런타임 완료를 의미하지 않는다.
